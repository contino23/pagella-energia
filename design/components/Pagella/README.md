# Pagella

Le quattro voci del voto con il loro peso: Prezzo 60%, Vincoli 20%, Trasparenza 10%, Venditore 10%.

- Ogni riga: nome della voce con il peso in `ink-muted`, barra a segmenti, voto.
- Finché il voto del venditore non è disponibile, la riga mostra una barra tratteggiata e "presto"; il suo peso si ripartisce sulle altre voci.
- Sotto la pagella, quando serve, i motivi in frasi brevi: "Penale se cambi fornitore prima della scadenza del prezzo bloccato".
