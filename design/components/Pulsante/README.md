# Pulsante

Il pulsante primario nero per l'unica azione principale della schermata, e il secondario con bordo per l'alternativa.

- **Primario** (`pe-btn`): fondo `ink`, testo bianco, icona in `luce`, alto 60px. Uno per schermata: "Carica la bolletta (PDF o foto)", "Ricalcola", "Vai all'offerta sul sito del venditore".
- **Secondario** (`pe-btn-secondary`): bordo `line-strong`, alto 52px. "Inserisci i dati a mano".
- In app i pulsanti principali occupano tutta la larghezza; sul sito si adattano al testo.
- Il testo dice esattamente cosa succede. Niente "Inizia" o "Scopri di più".
- Un link a un sito esterno porta la freccia in diagonale e apre una nuova scheda.
